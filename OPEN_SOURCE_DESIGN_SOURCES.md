# Invite Wala — Open-source design research

Research snapshot: 15 November 2026.

This catalogue expansion was informed by a search of GitHub repositories tagged/described as wedding invitations, digital invitations, wedding websites and invitation templates. Search surfaced more than 400 candidate repository results across overlapping queries. The following repositories were checked for repository-level licence metadata and used as design/interaction references where the licence was MIT.

## How the references were used

Invite Wala's 50 catalogue entries are original implementations with their own theme names, palettes, typography choices, CSS motifs and preview treatments. The references informed broad interaction and layout ideas—such as envelope opening, long-form mobile invitations, editorial layouts, floral/pastel themes, venue/event sections, glass-like layering and Indian ceremonial motifs.

No third-party repository images, photographs, videos, music or decorative assets were copied into this catalogue. Existing sample names, date and location in the preview are illustrative placeholders.

## Licence handling

- MIT was the inclusion threshold for considering source repositories for direct code reuse. The catalogue currently uses independently written HTML/CSS/JavaScript theme treatments rather than copying source code wholesale.
- A repository-level MIT licence does not automatically relicense images, fonts, music, videos or other separately credited assets in that repository. Those assets were not imported.
- Popular repositories carrying GPL-3.0/AGPL-3.0, and repositories with no declared licence or unclear asset permissions, were not used as source code or asset bundles. Examples reviewed included rampatra/wedding-website (GPL-3.0), vinitshahdeo/Wedding-Invitation (AGPL-3.0), sarthak-1998/WeddingEvite (AGPL-3.0), and sakeenah-wedding/template (no standard licence detected in repository metadata).

## Catalogue note

The 50 entries are 50 individually named and art-directed theme presets—not 50 cloned repositories and not 10,000 automatically permuted colour combinations. The gallery loads additional entries in batches so the initial page remains lightweight and the first designs can be displayed directly from the HTML.
